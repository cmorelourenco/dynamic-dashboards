# Dynamic dashboards

Browser based prototypes for the C-MORE dynamic dashboards experience.

## What it shows

The main prototype explores a dashboard library and editor for building reusable views of indicators. The library includes dashboard cards, sorting options, and a flow for creating or renaming dashboards. In the editor, users can add indicators, choose entities and periods, arrange charts, and switch between chart and comparison views. It also includes empty states and dashboard export controls. The interactions use sample data to demonstrate the experience; this is a design prototype, not a connection to live C-MORE data.

## Open

Open `dynamic-dashboards-v2.dc.html` in a browser to view the interactive dashboard prototype. Keep `support.js` and the `assets/` folder alongside it. Use `dynamic-dashboards-v2-empty.dc.html` for the empty-state variant.

The supporting pages can also be opened directly:

- `feedback-tracker.html` — dashboard feedback list
- `palette-swatches.html` — chart color palette

The dashboard prototype uses Google Fonts when a network connection is available.
